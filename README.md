# Sales Analysis Using Python

## Overview
A data analysis project using Python to explore customer purchasing behaviour, regional sales trends, and product performance through Exploratory Data Analysis (EDA).

## Objectives
- Analyze customer demographics and purchasing patterns.
- Identify high-performing states and customer segments.
- Examine product demand and order distribution.
- Generate actionable insights through data visualization.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure
- `notebooks/` – Jupyter Notebook containing analysis.
- `data/` – Dataset instructions and permitted data files.
- `images/` – Analysis visualizations.

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Place the permitted dataset in the `data/` directory.
4. Open the notebook using Jupyter Notebook.
5. Execute the cells sequentially.

## Key Analysis
- Gender-wise purchasing behaviour.
- Age-group sales distribution.
- State-wise sales and orders.
- Occupation-based purchasing patterns.
- Top-performing products.
